# باجه‌ی فروش چیز — CHIZ Booth

نرم‌افزار باجه‌ی فروش نیمه‌اتوماتیک برند **«چیز»** (ابزار سرگرمی دستی، ساخته‌شده از تخته‌اسکیت‌های شکسته). روی **رزبری‌پای** اجرا می‌شود و این‌ها را دارد:

- صفحه‌ی **۴۸۰×۸۰۰ عمودی** (غیرلمسی، با دکمه) با ظاهر کمیک و رنگ‌های برند.
- **۸ دکمه:** ۶ دکمه کنار ۶ کالا (۱، ۳، ۵ سمت چپ؛ ۲، ۴، ۶ سمت راست)، دکمه‌ی **قرمز** تأیید (تنها دکمه‌ی چراغ‌دار) و **انصراف**.
- **سبد خرید** و پرداخت با **کیوآر (زرین‌پال)** یا **کارتخوان**؛ هر دو خودکار تأیید می‌شوند.
- **قفل برقی ویترین** و **سنسور در**: بعد از پرداخت قفل باز می‌شود و با باز شدن در شمارش معکوس شروع می‌شود (۲۰ ثانیه + ۵ ثانیه برای هر قلم اضافه).
- **نورپردازی با دو ماسفت** (نور اصلی و نور قرمز) و افکت‌های هم‌زمان با جریان خرید و موزیک.
- **پنل مدیریت** روی گوشی: محصولات، موجودی، سفارش‌ها، گزارش و خروجی CSV.

باجه نیمه‌اتوماتیک است: وقتی در ویترین باز است همه‌ی کالاها در دسترس‌اند، پس **همیشه یک اپراتور کنار باجه هست**.

## مسیر خرید

```
صفحه‌ی اول ──قرمز──▶ منوی ۶ کالا ──دکمه‌ی کنار کالا──▶ +۱ به سبد (و جزئیات)
                          │  انصراف = برداشتن آخری
                        قرمز
                          ▼
                    بازبینی سبد ──قرمز──▶ روش پرداخت: ۱ = کیوآر   ۲ = کارتخوان ──قرمز──▶ پرداخت
                                                                                        │ خودکار
                                                                                        ▼
        صفحه‌ی اول ◀── در بسته شد ◀── شمارش معکوس (سنسور در) ◀── قفل باز ◀── پرداخت موفق (انیمیشن + موزیک)
```

## شروع سریع

**روی لپ‌تاپ (شبیه‌ساز):**

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
make preview    # محصولات نمونه + عکس همه‌ی صفحه‌ها در data/preview/
make sim        # باجه در پنجره؛ کلیدها: Enter=قرمز، 1..6=کالا، Esc=انصراف، d=در
make panel      # پنل: http://localhost:8000/admin  (PIN 1390)
```

**روی رزبری‌پای:** راهنمای قدم‌به‌قدم → **[docs/setup-pi.md](docs/setup-pi.md)**

```bash
bash scripts/install_pi.sh --test   # تست روی دسکتاپ
bash scripts/install_pi.sh          # نصب کامل کیوسک
```

## ساختار پروژه

```
kiosk/      برنامه‌ی صفحه‌ی باجه (Pygame-CE): صفحه‌ها، تم، ویجت‌ها، صدا
core/       دیتابیس SQLite، محصولات، سفارش‌ها، تنظیمات، پرداخت (زرین‌پال، کارتخوان)
hardware/   دکمه‌ها، قفل، سنسور در، لامپ دکمه‌ی قرمز، نورهای ماسفت، نوار LED
admin/      پنل مدیریت (FastAPI)
deploy/     سرویس‌های systemd
scripts/    نصب رزبری، تست سیم‌کشی، بکاپ، هات‌اسپات، پیش‌نمایش صفحه‌ها
assets/     فونت‌ها و تصاویر برند
tests/      تست‌ها:  make test
```

## تنظیمات

همه‌ی تنظیمات در `booth.toml` هستند (نمونه: [booth.toml.example](booth.toml.example)): صفحه، پرداخت، پایه‌های GPIO، تایمر در، نورها و کلیدهای دکمه‌ها. متغیرهای `CHIZ_*` بر فایل اولویت دارند.

## نکته‌ها

- فونت برند (سینا، `SSINABD.TTF`) کپی‌رایت دارد و در گیت نیست؛ روی هر دستگاه دستی کپی می‌شود ([assets/fonts/README.md](assets/fonts/README.md)).
- اتصال واقعی کارتخوان به پروتکل PSP بستگی دارد و بعد از خرید دستگاه نوشته می‌شود؛ تا آن موقع کارتخوانِ شبیه‌ساز فعال است.
