# راه‌اندازی باجه‌ی چیز روی رزبری‌پای — قدم به قدم

این راهنما از یک کارت حافظه‌ی خالی شروع می‌کند و به باجه‌ای می‌رسد که با روشن شدن، خودش بالا می‌آید.
دو مسیر دارد:

- **مسیر الف — تست سریع (حدود ۳۰ دقیقه):** برنامه را روی دسکتاپ رزبری‌پای در یک پنجره اجرا می‌کنی. چیزی موقع بوت خودکار اجرا نمی‌شود و همه‌چیز برگشت‌پذیر است. **برای الان همین را برو.**
- **مسیر ب — نصب کامل کیوسک:** باجه با روشن شدن مستقیم صفحه‌ی فروش را تمام‌صفحه نشان می‌دهد و پنل مدیریت و بکاپ هفتگی هم خودکار اجرا می‌شوند.

> هر دستوری که در کادر آمده را در ترمینال رزبری‌پای اجرا کن، مگر اینکه نوشته باشد «روی لپ‌تاپ».

---

## ۰. چیزهایی که لازم داری

| قطعه | توضیح |
|---|---|
| رزبری‌پای | Pi 3 B+ یا Pi 4 یا Pi 5. همه کار می‌کنند. Pi 4 با ۲ گیگ رم راحت‌تر است. |
| کارت microSD | حداقل ۱۶ گیگ، کلاس A1 یا بهتر (مثلاً سن‌دیسک Extreme / Samsung EVO). |
| منبع تغذیه | آداپتور اصلی رزبری: Pi 3 → ۵V ۲.۵A، Pi 4 → ۵V ۳A تایپ‌سی، Pi 5 → ۵V ۵A. آداپتور ضعیف باعث هنگ و خرابی کارت حافظه می‌شود. |
| مانیتور | مانیتور ۴۸۰×۸۰۰ عمودی باجه، یا هر مانیتور HDMI برای تست. |
| کیبورد و ماوس USB | فقط برای راه‌اندازی و تست. در باجه، انکودر USB دکمه‌ها جای کیبورد را می‌گیرد. |
| اینترنت | وای‌فای یا کابل LAN، برای نصب برنامه‌ها. |
| لپ‌تاپ | برای نوشتن کارت حافظه و کپی فایل فونت. |

---

## ۱. نوشتن سیستم‌عامل روی کارت حافظه (روی لپ‌تاپ)

1. برنامه‌ی **Raspberry Pi Imager** را از سایت raspberrypi.com نصب و اجرا کن.
2. **Device:** مدل رزبری‌ات را انتخاب کن.
3. **Operating System:**
   - برای مسیر الف (تست): `Raspberry Pi OS (64-bit)`، نسخه‌ی دسکتاپ‌دار.
   - برای باجه‌ی نهایی هم همین خوب است. اسکریپت نصب کامل، دسکتاپ را موقع بوت کنار می‌گذارد. اگر از اول فقط کیوسک می‌خواهی، `Raspberry Pi OS Lite (64-bit)` سبک‌تر است.
   - حتماً نسخه‌ی **Bookworm** (یا جدیدتر) و **۶۴ بیتی**.
4. **Storage:** کارت حافظه را انتخاب کن.
5. وقتی پرسید «Would you like to apply OS customisation settings?» روی **Edit Settings** بزن و این‌ها را پر کن:
   - **hostname:** `chiz` ← بعداً پنل را با `chiz.local` باز می‌کنی.
   - **username / password:** هر چه دوست داری، مثلاً `chiz` با یک رمز محکم. اسم کاربر هر چه باشد، اسکریپت نصب با آن کار می‌کند.
   - **Wireless LAN:** اسم و رمز وای‌فای + **Wireless LAN country: IR**.
   - **Locale:** Time zone `Asia/Tehran`، Keyboard `us`.
   - در تب **Services:** تیک **Enable SSH** را بزن، با گزینه‌ی رمز عبور.
6. **Save** → **Yes** → صبر کن تا نوشتن و Verify تمام شود.

---

## ۲. اولین روشن شدن

1. کارت را در رزبری بگذار، مانیتور، کیبورد و ماوس را وصل کن و بعد برق را.
2. اولین بوت ۱ تا ۳ دقیقه طول می‌کشد. چند بار ری‌استارت شدن عادی است.
3. ترمینال باز کن (دسکتاپ: آیکون ترمینال بالای صفحه). یا از لپ‌تاپ با SSH وصل شو:

   ```bash
   ssh chiz@chiz.local
   ```
   (`chiz` اول همان username مرحله‌ی ۱ است.)

4. سیستم را به‌روز کن:

   ```bash
   sudo apt update && sudo apt full-upgrade -y
   sudo reboot
   ```

## ۳. گرفتن پروژه

```bash
cd ~
git clone https://github.com/amirefarjami/salesbooth.git
cd salesbooth
```

### فونت برند (سینا) — دستی

فونت `SSINABD.TTF` در گیت نیست، چون کپی‌رایت دارد و ریپو عمومی است. از **لپ‌تاپ** کپی‌اش کن:

```bash
scp ~/Downloads/SSINABD.TTF chiz@chiz.local:~/salesbooth/assets/fonts/
```
(روی لپ‌تاپ اجرا می‌شود. اگر SSH نداری، فایل را با فلش روی رزبری بریز و در پوشه‌ی `~/salesbooth/assets/fonts/` بگذار.)

بدون این فایل هم برنامه کار می‌کند و تیترها با لاله‌زار نوشته می‌شوند.

## مسیر الف — تست سریع روی دسکتاپ

### الف-۱. نصب

```bash
cd ~/salesbooth
bash scripts/install_pi.sh --test
```

این کارها را می‌کند (۱۰ تا ۲۰ دقیقه، بسته به اینترنت):
- بسته‌های لازم سیستم (SDL، lgpio، sqlite و …) را نصب می‌کند.
- محیط پایتون `.venv` را می‌سازد و کتابخانه‌ها را نصب می‌کند.
- `booth.toml` را از روی نمونه می‌سازد.
- ۶ محصول نمونه با عکس اضافه می‌کند.
- **هیچ سرویسی فعال نمی‌کند** و دسکتاپ دست‌نخورده می‌ماند.

بعد از نصب یک بار **خروج و ورود دوباره** (یا `sudo reboot`) لازم است تا دسترسی کاربر به GPIO و صدا فعال شود.

### الف-۲. اجرای باجه

```bash
cd ~/salesbooth
make sim-fullscreen
```

- صفحه‌ی باجه تمام‌صفحه می‌آید و اندازه‌اش با مانیتور جور می‌شود.
- اگر پنجره‌ای می‌خواهی: `make sim` (پنجره‌ی ۴۸۰×۸۰۰؛ روی مانیتورهای کوتاه‌تر از ۸۰۰ پیکسل جا نمی‌شود).
- اگر مانیتورت افقی (۸۰۰×۴۸۰) است ولی می‌خواهی عمودی ببینی، در `booth.toml` بنویس `screen_rotate = 90`.

### الف-۳. کلیدها در حالت تست

| کلید | دکمه‌ی باجه |
|---|---|
| `Enter` | دکمه‌ی قرمز (شروع، سبد، پرداخت) |
| `1` `3` `5` | دکمه‌های سمت چپ مانیتور (بالا، وسط، پایین) |
| `2` `4` `6` | دکمه‌های سمت راست |
| `Esc` | انصراف |
| `d` | باز و بسته کردن در ویترین (شبیه‌ساز سنسور) |
| `Ctrl+Q` | بستن برنامه |

**یک خرید کامل:**
1. `Enter` را بزن.
2. با `1` و `4` کالا به سبد اضافه کن.
3. `Enter` را بزن تا سبد باز شود، و دوباره `Enter`.
4. `2` (کارتخوان) و بعد `Enter`. کارتخوانِ شبیه‌ساز ۵ ثانیه بعد خودش تأیید می‌کند.
5. انیمیشن پرداخت موفق و موزیک پخش می‌شود.
6. `d` را بزن: در باز می‌شود و شمارش معکوس شروع می‌شود.
7. دوباره `d`: در بسته می‌شود و «ممنون از خریدت!» می‌آید.

### الف-۴. پنل مدیریت

در یک ترمینال دیگر:

```bash
cd ~/salesbooth
make panel
```

از گوشی یا لپ‌تاپ که به همان شبکه وصل است: `http://chiz.local:8000/admin`، با PIN `1390`.
آنجا محصول اضافه می‌کنی، عکس می‌گذاری، موجودی و قیمت را عوض می‌کنی و گزارش فروش می‌بینی.
باجه فقط **۶ محصول اول** (به ترتیب «ترتیب نمایش») را نشان می‌دهد، چون ۶ دکمه دارد.

تست تمام شد؟ `Ctrl+C` در ترمینال پنل، و `Ctrl+Q` در باجه.

## مسیر ب — نصب کامل کیوسک

وقتی سخت‌افزار باجه (مانیتور، انکودر دکمه‌ها، قفل، سنسور، نورها) وصل شد.

### ب-۱. تنظیمات `booth.toml`

```bash
cd ~/salesbooth
nano booth.toml
```

مهم‌ترین‌ها (بقیه توضیح خودشان را دارند):

```toml
[booth]
fullscreen = true
screen_rotate = 0          # 90 یا 270 اگر پنل ۸۰۰×۴۸۰ افقی نصب شده

admin_pin = "یک رمز تازه"   # PIN پنل؛ حتماً عوضش کن

payment_methods = ["qr", "card"]
zarinpal_sandbox = true    # تا وقتی درگاه واقعی نگرفته‌ای
pos_driver = "sim"         # تا وقتی درایور کارتخوان واقعی نوشته نشده (docs/card-reader.md)

door_open_s = 20           # تایمر در برای ۱ قلم
door_extra_per_item_s = 5  # +۵ ثانیه برای هر قلم اضافه

# پایه‌ها — باید با سیم‌کشی یکی باشد (docs/wiring.md)
lock_gpio = 17
door_sensor_gpio = 27
red_light_gpio = 22
booth_light_gpio = 12
warn_light_gpio = 13
led_enabled = false        # فقط اگر نوار WS2812 داری true کن
```

ذخیره در nano: `Ctrl+O`، `Enter`، و خروج با `Ctrl+X`.

### ب-۲. تست سیم‌کشی قبل از بستن بدنه

روی دسکتاپ (قبل از نصب کامل) یا با یک مانیتور:

```bash
cd ~/salesbooth
make factory-test
```

- هر دکمه‌ای را بزن؛ اسمش روی صفحه می‌آید. باید ۸ دکمه را ببینی: کالا ۱ تا ۶، تأیید و انصراف.
- **دکمه‌ی قرمز:** لامپش، رله‌ی قفل و حالت هشدار نورها (ماسفت ۱ کم‌نور و ماسفت ۲ قرمز) یک ثانیه روشن می‌شوند.
- **در ویترین را باز و بسته کن:** بالای صفحه باید «باز» و «بسته» عوض شود.
- خروج: `Ctrl+Q`.

اگر دکمه‌ای اشتباه است، کلیدهای انکودر را در `[booth.keymap]` همان `booth.toml` جابه‌جا کن.

### ب-۳. نصب

```bash
cd ~/salesbooth
bash scripts/install_pi.sh
sudo reboot
```

این نسخه علاوه بر کارهای مسیر الف:
- سه سرویس را فعال می‌کند:
  - `chiz-kiosk`: صفحه‌ی باجه.
  - `chiz-admin`: پنل مدیریت روی پورت ۸۰۰۰.
  - `chiz-backup.timer`: بکاپ دیتابیس، یکشنبه‌ها ساعت ۴ صبح، با نگه داشتن ۸ نسخه‌ی آخر.
- رزبری را طوری تنظیم می‌کند که **به‌جای دسکتاپ در حالت کنسول بوت شود**. باجه خودش مستقیم روی صفحه نقاشی می‌کند و دسکتاپ نباید جلویش باشد.
- خاموش شدن خودکار صفحه را غیرفعال می‌کند.

بعد از ری‌استارت، باید خودکار صفحه‌ی اول باجه (لوگو و «دکمه‌ی قرمز رو بزن») بیاید.

برگرداندن دسکتاپ (اگر لازم شد):

```bash
sudo systemctl disable chiz-kiosk
sudo systemctl set-default graphical.target
sudo reboot
```

### ب-۴. وضعیت و لاگ‌ها

```bash
systemctl status chiz-kiosk chiz-admin      # در حال اجرا هستند؟
journalctl -u chiz-kiosk -f                 # لاگ زنده‌ی باجه (خروج: Ctrl+C)
journalctl -u chiz-kiosk -b --no-pager | tail -50   # خطاهای این بوت
sudo systemctl restart chiz-kiosk           # اجرای دوباره‌ی باجه
```

### ب-۵. وای‌فای اختصاصی باجه (اختیاری)

رزبری یک وای‌فای به اسم `CHIZ-BOOTH` می‌سازد تا فروشنده از گوشی به پنل وصل شود، حتی بدون مودم:

```bash
bash scripts/setup_hotspot.sh "CHIZ-BOOTH" "یک‌رمز‌حداقل۸حرفی" wlan0
```

پنل: `http://10.42.0.1:8000/admin`.
برای اینترنت پرداخت (زرین‌پال، کارتخوان) در این حالت، رزبری را با **کابل LAN** به مودم وصل کن.

### ب-۶. صدا

صدا به‌طور پیش‌فرض از HDMI یا جک ۳.۵ میلی‌متری پخش می‌شود. اگر صدایی نمی‌آید:

```bash
sudo raspi-config     # System Options → Audio → خروجی درست را انتخاب کن
```

(Pi 5 جک صدا ندارد؛ از صدای HDMI یا یک کارت صدای USB استفاده کن.)

## ۴. به‌روزرسانی برنامه

هر وقت تغییر تازه‌ای در گیت آمد:

```bash
cd ~/salesbooth
git pull
.venv/bin/pip install -r requirements.txt
sudo systemctl restart chiz-kiosk chiz-admin
```

`booth.toml`، دیتابیس (`data/`) و فونت سینا دست نمی‌خورند.

## ۵. بکاپ و بازگردانی

- بکاپ‌ها در `~/salesbooth/data/backups/` هستند (`booth-YYYY-MM-DD_HHMM.db.gz`).
- بکاپ دستی همین الان: `bash scripts/backup_db.sh`
- بازگردانی:

  ```bash
  sudo systemctl stop chiz-kiosk chiz-admin
  gunzip -c data/backups/booth-2026-10-04_0400.db.gz > data/booth.db
  sudo systemctl start chiz-kiosk chiz-admin
  ```

## ۶. اگر چیزی کار نکرد

راهنمای کامل عیب‌یابی: [troubleshooting.md](troubleshooting.md). سریع‌ترین چک‌ها:

| مشکل | اول این را ببین |
|---|---|
| صفحه‌ی سیاه بعد از نصب کامل | `journalctl -u chiz-kiosk -b` — اگر `kmsdrm` خطا داد، دسکتاپ هنوز فعال است (ب-۳ را دوباره اجرا کن) |
| دکمه‌ها کار نمی‌کنند | کاربر در گروه `input` نیست → `sudo reboot` بعد از نصب؛ یا keymap اشتباه است (ب-۲) |
| قفل، سنسور یا نورها کار نمی‌کنند | `make factory-test`؛ شماره‌ی GPIO در `booth.toml` با سیم‌کشی یکی باشد |
| حروف فارسی مربع مربع | فونت‌ها: `ls assets/fonts` — باید Vazirmatn و Lalezar باشند |
| `chiz.local` باز نمی‌شود | IP را با `hostname -I` روی رزبری ببین و `http://IP:8000/admin` را بزن |
