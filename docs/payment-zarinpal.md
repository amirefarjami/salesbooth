# پرداخت با کیوآر (زرین‌پال) — از سندباکس تا حساب واقعی

خریدار در صفحه‌ی «روش پرداخت» **دکمه‌ی ۱** (کیوآر) را می‌زند. باجه یک لینک پرداخت زرین‌پال می‌سازد و کیوآرش را نشان می‌دهد. خریدار با دوربین گوشی اسکن می‌کند و در صفحه‌ی بانک پرداخت می‌کند. باجه هر چند ثانیه از زرین‌پال می‌پرسد و به‌محض تأیید، **خودکار** به صفحه‌ی پرداخت موفق می‌رود. اپراتور کاری لازم نیست بکند.

## ۱. سندباکس (پیش‌فرض)

```toml
# booth.toml
[booth]
payment_methods = ["qr", "card"]
zarinpal_sandbox = true
zarinpal_merchant_id = ""      # خالی = مرچنت سندباکس
```

در سندباکس پول واقعی جابه‌جا نمی‌شود. برای تست صفحه‌ی بانک سندباکس را کامل کن.

## ۲. رفتن روی حساب واقعی

1. از زرین‌پال درگاه بگیر (حساب کاربری، احراز هویت، شماره‌ی شبا). یک **مرچنت‌کد** ۳۶ کاراکتری می‌دهند.
2. روی رزبری:
   ```bash
   nano ~/salesbooth/booth.toml
   ```
   ```toml
   zarinpal_sandbox = false
   zarinpal_merchant_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
   ```
3. `sudo systemctl restart chiz-kiosk`
4. یک خرید واقعی کوچک انجام بده و در پنل → «گزارش»، ستون provider = `zarinpal` و شماره‌ی پیگیری را ببین.

## ۳. نکته‌ها

- **اینترنت لازم است.** هم برای ساختن لینک و هم برای استعلام. با کابل LAN یا مودم 4G.
- مبالغ در پنل به **تومان** وارد می‌شوند؛ آداپتور خودش ×۱۰ می‌کند و ریال می‌فرستد.
- تماس‌های شبکه در پس‌زمینه انجام می‌شوند، پس صفحه هیچ‌وقت هنگ نمی‌کند.
- اگر خریدار تا `payment_timeout_s` (پیش‌فرض ۱۸۰ ثانیه) پرداخت نکند، سفارش لغو می‌شود و موجودی برمی‌گردد. با دکمه‌ی قرمز می‌شود دوباره امتحان کرد.
- سفارش‌هایی که به‌خاطر قطع برق نیمه‌کاره ماندند، در بوت بعدی بعد از `order_ttl_minutes` (پیش‌فرض ۳۰ دقیقه) لغو می‌شوند و موجودی‌شان برمی‌گردد.
- اگر درگاه مشکل داشت، فروشنده همیشه می‌تواند از پنل → داشبورد → «تأیید پرداخت (دستی)» سفارش را قطعی کند.
