# پرداخت زرین‌پال — از سندباکس تا حساب واقعی

## ۱. سندباکس (الان فعال می‌شه)

```toml
# booth.toml
[booth]
payment_provider = "zarinpal"
zarinpal_sandbox = true
zarinpal_merchant_id = ""   # خالی = مرچنت سندباکس
```

روی مانیتور باجه QR نمایش داده می‌شه؛ با گوشی اسکنش کن و با کارت سندباکس پرداخت کن.
باجه هر ۳ ثانیه استعلام می‌گیره (verify) و بعد از تأیید خودکار صفحه موفقیت + کد تحویل میاد.

## ۲. رفتن روی حساب واقعی

1. درگاه زرین‌پال بگیر (نیاز به حساب بانکی/پروانه — زرین‌پال راهنمای احراز داره).
2. فایل `booth.toml` روی Pi:
   ```toml
   payment_provider = "zarinpal"
   zarinpal_sandbox = false
   zarinpal_merchant_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
   ```
   یا با env: `CHIZ_ZARINPAL_MERCHANT_ID=... CHIZ_FULLSCREEN=1`
3. سرویس را ری‌استارت کن: `sudo systemctl restart chiz-kiosk`
4. یک خرید تستی واقعی انجام بده و در پنل `گزارش`، provider=`zarinpal` و ref_id چک کن.

مبالغ: زرین‌پال v4 ریال می‌گیرد؛ آداپتور خودش تومان×۱۰ می‌فرستد — قیمت‌ها در پنل تومان وارد می‌شوند.

## ۳. Fallback دستی (همیشه فعال)

اگر اینترنت قطع شد یا درگاه خطا داد، فروشنده همان لحظه از پنل گوشی
(داشبورد → سفارش‌های باز → «تأیید پرداخت») سفارش را قطعی می‌کند؛
کافیست مشتری پول را کارت بخوان (کارتخوان روی دک) و فروشنده تأیید بزند.
تأیید دستی هیچ‌وقت از دسترس خارج نمی‌شود چون پنل روی همان باجه است.

## ۴. نکات

- timeout پیش‌فرض انتظار پرداخت: ۱۸۰ ثانیه (`payment_timeout_s`)، بعدش سفارش لغو و موجودی برمی‌گردد.
- سفارش‌های pending قدیمی‌تر از `order_ttl_minutes` در بوت بعدی هم پاک می‌شوند (restock خودکار).
- QR برای «لینک StartPay» ساخته می‌شود؛ پکیج اختیاری `qrcode` را روی Pi نصب کن:
  `.venv/bin/pip install qrcode pillow`
